# LumenKey Secure Access Token Guide

> Fictional sample document created for the Agentic RAG demo. LumenKey is not a real product.

## 1. What LumenKey is

LumenKey is the multi-factor authentication (MFA) app used by employees to sign in to the Advisor Workstation and other internal systems. After entering a password, the user approves the sign-in on LumenKey or types the 6-digit code it shows.

## 2. Registering LumenKey for a new user

1. Install the LumenKey app from the company app store on a company-managed phone.
2. On a computer, open the **Access Portal** and choose **Register Token**.
3. Scan the QR code shown on screen with the LumenKey app.
4. Enter the 6-digit code from the app to confirm the registration.
5. The registration code expires after **15 minutes**. If it expires, start again from step 2.

Each user can have one active LumenKey device at a time.

## 3. Moving LumenKey to a new phone

1. While you still have the old phone, open the Access Portal and choose **Replace Token**.
2. Scan the new QR code with LumenKey on the new phone.
3. The old phone is deactivated automatically.

If the old phone is lost or broken, follow section 4 instead.

## 4. Lost or broken phone

1. Call the Service Desk at extension 4400.
2. The Service Desk verifies your identity and **revokes** the old token.
3. You receive a **temporary access code** valid for 8 hours, to sign in while you register a new device.
4. Register LumenKey on the new phone as described in section 2.

## 5. Common problems

| Problem | Solution |
|---|---|
| "Code not accepted" | Check the phone's date and time are set automatically. Codes depend on the correct time. |
| No approval notification | Open the LumenKey app manually and pull down to refresh, or use the 6-digit code instead. |
| "Token locked" | The token locks after 5 wrong codes. Wait 30 minutes, or ask the Service Desk to unlock it. |
| App asks to re-register | The token was revoked. Register again as described in section 2. |

## 6. Security rules

- Never share a LumenKey code, including with the Service Desk. Service Desk staff will never ask for it.
- Report unexpected approval requests immediately: they may mean someone knows your password.
